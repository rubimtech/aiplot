# aiplot

Слой автоматического распознавания графиков, который готовит черновик данных для
редактора ручной коррекции (human-in-the-loop). Сам редактор берётся из
`upstream/react-editor` и не патчится: интеграция идёт через его REST API.

## Что делает

1. Находит рамку графика и засечки осей.
2. Опционально читает подписи осей (Tesseract).
3. Строит калибровку «пиксель → значение» для линейной и логарифмической шкал.
4. Извлекает кривые:
   - `color` — кластеры по оттенку (цветные графики);
   - `line` — трассировка наклонных линий по строкам (номограммы на лог-сетке);
   - `ink` — компоненты связности (последний резерв).
5. Отбраковывает аннотации (горизонтальные/вертикальные маркеры, зигзаги).
6. Отдаёт JSON с пиксельными и уже пересчитанными значениями.
7. По `--push` создаёт сессию в редакторе: загружает картинку, ставит калибровку
   и заливает кривые точками с `origin: "ai"`.

## Запуск

```powershell
# backend редактора
.venv\Scripts\python -m uvicorn app.main:app --port 8000 --app-dir upstream/react-editor/backend
# UI редактора
npm run preview -- --port 5173 --prefix upstream/react-editor/frontend
# распознавание
.venv\Scripts\python -m aiplot.cli in\valve.png `
  --x-range 3 3000 --x-scale log --y-range 10 1000 --y-scale log `
  --overlay out\valve_overlay.png --json out\valve.json --push
```

`--overlay` рисует найденную рамку, засечки и трассы поверх исходника — это главный
инструмент проверки: видно, что именно распознано, до правки руками.

## HTTP

```powershell
.venv\Scripts\python -m uvicorn aiplot.service:app --port 8010 --app-dir ai
```

- `POST /recognize` — multipart `file` + `x_min/x_max/y_min/y_max`, `x_scale/y_scale`;
  возвращает полный JSON распознавания.
- `POST /recognize/push` — то же плюс создаёт сессию в редакторе (`base` — адрес API).
- `GET /health` — доступность OCR и адрес редактора по умолчанию.
- `GET /sessions/last` — id последней сессии и ссылка на UI.

## Режимы извлечения

| Режим | Когда | Что делает |
|---|---|---|
| `auto` | по умолчанию | цветные кривые, иначе трассировка линий |
| `color` | только цветные | кластеры по hue |
| `lines` | номограммы | трассировка наклонных линий |
| `ink` | последний резерв | компоненты связности без цвета |

## Ограничения (проверено на `in/valve.png`)

- Диапазоны осей и тип шкалы задаются **явно**. Автоугадывание декад по сетке
  убрано намеренно: на лог-миллиметровке второстепенные линии образуют вложенные
  прогрессии, и шаг определялся вдвое-втрое меньше истинного — калибровка молча
  уезжала. Лучше потребовать два числа, чем выдать правдоподобную чушь.
- OCR годится для чистых подписей; на сканах с наклонными кривыми, задевающими
  ось, он читает мусор. Поэтому цифры осей — параметр, а не магия.
- Пересекающиеся линии сливаются: на графике клапана семь почти параллельных
  кривых трассируются по отдельности, но реально пересекающиеся дадут склейку.
- `--max-curves` по умолчанию 8.

## Тесты

```powershell
cd ai; ..\.venv\Scripts\python -m pytest -q
```

- `test_recognize.py` — синтетический график с известной геометрией (регрессия точности).
- `test_valve.py` — реальный скан: рамка пиксель-в-пиксель, 7 кривых, монотонность,
  отсутствие дублей, калибровка сверена с напечатанными примерами `q=50`, `Δp=6000 Па`.

## Лицензии

`upstream/` содержит чужие репозитории без файла лицензии (значит «все права
защищены»). Они лежат локально и в git не попадают. Код в `ai/` — свой; чужой код
не копируется, используется только как отдельно запускаемый сервис.
